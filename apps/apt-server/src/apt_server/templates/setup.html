Setup

Public repository

Trust the signing key and register the repository:

curl -fsSL https://{{ host }}/pubkey.gpg \
  | sudo gpg --dearmor -o /etc/apt/keyrings/{{ keyring_name }}.gpg

echo "deb [signed-by=/etc/apt/keyrings/{{ keyring_name }}.gpg] https://{{ host }} {{ default_suite }} {{ default_component }}" \
  | sudo tee /etc/apt/sources.list.d/{{ keyring_name }}.list

sudo apt update
sudo apt install <package-name>

Private repository (PAT)

Private components require authentication. APT uses HTTP Basic Auth with your username and a Personal Access Token (PAT) as password.

1. Create a PAT

{% if issuer %}

Go to {{ issuer }}/auth/settings/tokens and create a new token:

{% else %}

Go to your SSO settings page (/auth/settings/tokens) and create a new token:

{% endif %}
  • Name: a descriptive label, e.g. laptop-apt
  • Expiration: 30, 90 or 365 days
  • Scopes: apt:read to install, apt:write to upload

Copy the token shown once (format gab_pat_…). It cannot be retrieved later.

2. Register credentials with APT

sudo install -m 0600 -o root -g root /dev/null /etc/apt/auth.conf.d/{{ keyring_name }}.conf

sudo tee /etc/apt/auth.conf.d/{{ keyring_name }}.conf > /dev/null <<'EOF'
machine {{ host }}
login {{ caller.display_name or 'your-email@example.com' }}
password gab_pat_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
EOF

login = your SSO email. password = PAT. File must be 0600 root:root.

3. Add the private source

echo "deb [signed-by=/etc/apt/keyrings/{{ keyring_name }}.gpg] https://{{ host }} {{ default_suite }} <private-component>" \
  | sudo tee /etc/apt/sources.list.d/{{ keyring_name }}-private.list

sudo apt update

4. Verify

curl -u '{{ caller.display_name or 'your-email' }}:gab_pat_xxxx' -I https://{{ host }}/dists/{{ default_suite }}/<component>/binary-amd64/Packages
# 200 = OK | 401 = bad PAT | 403 = wrong scope
