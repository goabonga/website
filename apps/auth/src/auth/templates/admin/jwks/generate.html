Larger keys provide more security but slower signing operations. 2048-bit is recommended for most use cases.

Key Generation Info

  • Keys are generated as RSA key pairs with RS256 algorithm
  • Private keys are encrypted with AES-256-GCM before storage
  • Public keys are exposed via the /.well-known/jwks.json endpoint
  • Only one key can be active at a time for signing
  • Inactive keys can be activated later when needed
