About Multi-Tenancy

Tenants represent organizations or companies that use this authentication service. Each tenant can have its own:

  • Slug - Used for subdomain access (e.g., acme.<base domain>)
  • Custom domain - Optional CNAME (e.g., login.acme.com)
  • Members - Users belonging to this organization
  • Identity providers - External IdPs like Google, GitHub, or OIDC providers
