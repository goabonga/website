Provider-Specific Setup

Generic OIDC (Keycloak, Auth0, Okta)

  1. Create an application in your OIDC provider
  2. Set the redirect URI to: https://auth.example.com/federation/callback
  3. Copy the Client ID and Client Secret
  4. Enter the discovery URL (usually ends with /.well-known/openid-configuration)

Google

  1. Go to Google Cloud Console
  2. Create OAuth 2.0 credentials
  3. Add authorized redirect URI: https://auth.example.com/federation/callback
  4. Copy Client ID and Client Secret

GitHub

  1. Go to GitHub Developer Settings
  2. Create a new OAuth App
  3. Set the callback URL to: https://auth.example.com/federation/callback
  4. Copy Client ID and generate a Client Secret

Microsoft / Azure AD

  1. Go to Azure App Registrations
  2. Register a new application
  3. Add redirect URI: https://auth.example.com/federation/callback
  4. Create a client secret under "Certificates & secrets"
  5. Use discovery URL: https://login.microsoftonline.com/{tenant-id}/v2.0/.well-known/openid-configuration
