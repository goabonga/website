Installation

🐧 Linux / macOS

chmod +x knowledge-mcp ./knowledge-mcp --help

Make the binary executable and run it. Add to your PATH for easy access.

💻 Windows

knowledge-mcp.exe --help

Run the executable directly from Command Prompt or PowerShell.

⚙ Configuration

export KNOWLEDGE_API_KEY="your-api-key" export KNOWLEDGE_BASE_URL="{{ site().base_url or 'https://knowledge.example.com' }}"

Set environment variables for authentication.

🔗 Claude Desktop

{ "mcpServers": { "knowledge": { "command": "/path/to/knowledge-mcp" } } }

Add to your Claude Desktop config file.
