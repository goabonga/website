# Data model

This feature defines what the service stores: the SQLAlchemy models, the
`domainstatus` enum and the initial alembic migration. Later features read and
write these tables; none of them adds a table.

## Models

All models live in `custom_domain.models` and share the declarative `Base`.

### `CustomDomain` (table `custom_domains`)

| Column | Type | Notes |
| --- | --- | --- |
| `id` | UUID | Primary key, generated by the application. |
| `domain` | string(255) | Indexed. Unique among rows whose `deleted_at` is null (partial unique index `ix_custom_domains_domain_unique`), so a soft-deleted name can be registered again. |
| `deleted_at` | timestamp with time zone | Soft-delete marker, indexed. |
| `client_id` | string(255) | OAuth2 client that owns the domain, indexed. |
| `owner_id`, `owner_type` | string | Tenant identifier (organisation, user, ...) and its kind. `owner_id` is indexed; `(client_id, owner_id)` has a composite index. |
| `upstream_target` | string(500) | Socket or URL nginx proxies to. |
| `status` | `domainstatus` | Defaults to `pending`, indexed. |
| `cname_target` | string(255) | CNAME the customer must create. |
| `dns_verified_at`, `ssl_provisioned_at`, `ssl_expires_at`, `last_check_at` | timestamp | Lifecycle timestamps. |
| `error_message` | text | Last error. |
| `retry_count` | integer | Failed verification attempts. |
| `nginx_template_id` | integer | Optional foreign key to `nginx_templates`. |
| `metadata` | JSONB | Free-form metadata (attribute `metadata_`). |
| `created_at`, `updated_at` | timestamp | Server-side `now()`; `updated_at` is refreshed on update. |

### `AuthorizedClient` (table `authorized_clients`)

An OAuth2 client allowed to register domains, with the defaults applied when a
domain omits them.

| Column | Type | Notes |
| --- | --- | --- |
| `id` | integer | Primary key. |
| `client_id` | string(255) | Unique, indexed. |
| `name`, `description` | string, text | Display data. |
| `default_upstream_target` | string(500) | Default upstream for the client's domains. |
| `default_cname_target` | string(255) | Default CNAME target. |
| `default_nginx_template_id` | integer | Optional foreign key to `nginx_templates`. |
| `max_domains` | integer | Quota; null means unlimited. |
| `is_active` | boolean | Inactive clients cannot register domains. |
| `metadata`, `created_at`, `updated_at` | JSONB, timestamps | As above. |

### `NginxTemplate` (table `nginx_templates`)

A pair of Jinja2 templates (HTTP-only for the ACME challenge, then full
HTTPS).

| Column | Type | Notes |
| --- | --- | --- |
| `id` | integer | Primary key. |
| `slug` | string(100) | Unique, indexed. |
| `name`, `description` | string, text | Display data. |
| `http_template`, `https_template` | text | Jinja2 sources. |
| `is_default` | boolean | The default template (partial index on the true rows). |
| `is_active` | boolean | Inactive templates are never selected. |
| `available_variables` | JSONB list | Variables documented for template authors. |
| `created_at`, `updated_at` | timestamp | As above. |

### `DomainStatus`

`pending`, `dns_verifying`, `dns_verified`, `ssl_provisioning`, `active`,
`failed`, `suspended`, `expired`, `deprovisioning`. It is stored as the
PostgreSQL enum `domainstatus` using the lowercase values. `deprovisioning` is
the transient state of a domain whose deletion was requested: the API only
marks the domain and a worker removes the nginx file and revokes the
certificate (Domain API page).

## Migration

`alembic/versions/001_initial.py` creates the enum, the three tables, their
indexes and the foreign keys (`ON DELETE SET NULL`), and `downgrade()` removes
them. The environment script (`alembic/env.py`) reads `DATABASE_URL` directly
(default `postgresql:///custom_domain`) and always connects with the
`psycopg2` driver; any `+asyncpg` suffix is stripped.

```bash
export DATABASE_URL=postgresql://user:password@localhost/custom_domain
uv run --package custom-domain alembic -c apps/custom-domain/alembic.ini upgrade head
```

Add `--sql` to print the SQL instead of running it.

## How it is tested

- pytest: `test_models.py` (enum values, in-memory instances and Python-side
  defaults of each model, soft-delete marker) and `test_migrations.py`, which renders the migration as offline
  SQL and checks the revision graph, that every model table is created, the
  enum values, the partial unique index and the downgrade.
- behave: `features/data_model.feature` with *The initial migration creates
  every table*, *The migration can be reverted*, *A new domain starts pending
  with no retries*, *A soft-deleted domain name can be registered again* and
  *Two live domains cannot share a name*. The model scenarios run on an
  in-memory SQLite database created from the same metadata (`features/fakes.py`
  maps JSONB to JSON and recreates the partial unique index), so no PostgreSQL
  server is needed.
